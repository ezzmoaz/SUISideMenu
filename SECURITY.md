# Security Policy

## Supported Versions

The latest minor release receives security fixes. Older versions are supported
on a best-effort basis.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

SUISideMenu is a UI component with no networking, persistence, or credential
handling, so the security surface is small. If you do find a vulnerability:

- **Do not** open a public issue.
- Email **moazezz45@gmail.com** with a description, affected versions, and a
  reproduction if possible.

You can expect an acknowledgement within a few days. Once a fix is available it
will be released and credited (unless you prefer to remain anonymous).
